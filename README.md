# MoCoLike_Demo_Art

MoCoLike 專案 Demo 專用美術資產。

## 資產現況

### Pack-Adventures

目前包含 **FashionBoy** 角色資源，共 10 個檔案：

- 1 個 FBX 角色模型
- 5 個 JPEG 材質貼圖：Base Color、Metallic、Normal、RM、Roughness
- 4 張 PNG 預覽圖：Front、Back、LeftSide、Front T-Pose

資產主要位於：

- `Pack-Adventures/Assets/FashionBoy/`：模型與材質資源
- `Pack-Adventures/Samples/`：角色預覽圖
